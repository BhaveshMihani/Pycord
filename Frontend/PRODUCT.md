# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

React, Vite, TypeScript, TailwindCSS, FastAPI, MongoDB

## Users

Friends and developers looking for a fast, simple place to chat and share code.

## Product Purpose

A realtime chatting application where friends can create rooms and share code to chat with each other.

## Positioning

A lightweight, frictionless alternative to Discord that focuses purely on fast room creation and seamless code sharing among friends.

## Operating Context

Desktop and mobile web browsers, likely used alongside IDEs or during collaborative gaming/coding sessions.

## Capabilities and Constraints

- Realtime chat
- Room-based architecture with unique invite codes
- Code sharing support
- Clerk authentication

## Brand Commitments

- Sleek, fast, "developer/gamer" dark mode aesthetic.
- Frictionless entry (easy room generation and joining).
